# Rezeptbuch – flexitarisch & schnell

Persönliches Rezeptbuch mit schnellen Alltagsgerichten: überwiegend vegetarisch/vegan, wenig Fleisch, viele Rezepte für die Heißluftfritteuse (Airfryer).

**Funktionen**
- Rund 60 Rezepte, Suche auch nach Zutaten („was hab ich im Kühlschrank?“)
- Filter: Veggie, Vegan, Fisch, Wenig Fleisch · Airfryer · ≤ 15 / ≤ 25 Min · Meal Prep · Favoriten
- 🎲 „Was koche ich?“ – Zufallsrezept aus der aktuellen Auswahl
- Portionen umrechnen, Zutaten abhaken, Timer direkt im Schritt, Bildschirm-anlassen-Modus
- Veggie-Tausch-Tipps bei Fleischrezepten
- Wochenplan mit Flexi-Ziel (max. Fleischgerichte/Woche) und automatischem Auffüllen
- Einkaufsliste (fasst gleiche Zutaten zusammen, teilen/kopieren)
- 🌍 **Entdecken**: Hunderte weitere Rezepte aus [TheMealDB](https://www.themealdb.com) (kostenlos, ohne Anmeldung) – nach Kategorie (Vegetarisch, Vegan, Fisch, Pasta …), Zutat (auch auf Deutsch, z. B. „Kürbis“) oder Zufall. Mengen werden automatisch in g/ml/EL umgerechnet, Anleitungen sind auf Englisch (Übersetzen-Knopf). Mit „Ins Buch übernehmen“ landen sie offline im eigenen Rezeptbuch.
- Eigene Rezepte anlegen, Sicherung als Datei

Läuft als installierbare Web-App über GitHub Pages, auch offline.
Am Handy: Adresse öffnen, dann „Zum Home-Bildschirm“ (iPhone, Teilen-Symbol) bzw. „Zum Startbildschirm hinzufügen“ (Android, Menü ⋮).

Neue Rezepte fürs ganze Buch kommen in `recipes.js`.
